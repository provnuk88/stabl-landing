# STABL.FUN — лендинг

**Живая ссылка (превью для заказчика):** https://provnuk88.github.io/stabl-landing/

Статика. Ни сборки, ни зависимостей — папку можно класть на любой хостинг как есть.

## Про превью-ссылку

Раздаётся с GitHub Pages из **публичного** репозитория `provnuk88/stabl-landing` — на бесплатном тарифе Pages иначе не работает. Значит исходники видны всем, у кого есть ссылка на репозиторий.

Снести целиком:

```bash
gh repo delete provnuk88/stabl-landing --yes
```

Обновить после правок:

```bash
cd E:\stabl\landing
git add -A && git commit -m "..." && git push
# Pages пересобирается за минуту
```

**Перед боевым запуском обязательно снять:**
- `<meta name="robots" content="noindex, nofollow">` в `index.html`
- `Disallow: /` в `robots.txt`
- вернуть `<link rel="canonical" href="https://stabl.fun/">`
- переписать `og:url`, `og:image`, `twitter:image` с github.io на stabl.fun

## Как устроен герой

Два типа материала, и это осознанно:

| | Что это | Почему так |
|---|---|---|
| **Галоп** | `gallop.mp4`, автоплей в цикле | Скачет сам. Герой живой до того, как юзер тронул колесо |
| **Ложа** | 45 кадров WebP, скраб по скроллу | Читатель сам проявляет лица — это его действие, а не таймер |

Сцена приколота (`position: sticky`) на всю высоту героя — 300vh. Прогресс скролла внутри неё:

```
p 0     → 0.14   галоп в цикле, заголовок стоит, лента торгуется
p 0.14  → 0.32   заголовок уходит
p 0.35           ФИНИШ: рынок схлопывается в 100¢ / 0¢, лента Live → Settled,
                 экран передаётся ложе
p 0.35  → 0.62   скраб реакции, 45 кадров
p 0.62  → 1.00   последний кадр ДЕРЖИТСЯ
p 0.58  → 0.72   CTA и лента уходят, чтобы не торчать из-под карточек
p 0.60  →        секция маркетов выезжает снизу ПОВЕРХ застывшего кадра
```

Наезд сделан отрицательным `margin-top: -80vh` на `.band--markets` плюс `z-index: 5`. Фон у секции прозрачный, а читаемость держит градиентный скрим в `::before` — поэтому лица видны сквозь верхний край, а к середине секции всё уходит в холст.

Цена не декоративная: она считается от позиции скролла, дрейфует вверх по мере приближения к столбу и подрагивает двумя синусоидами, чтобы лента не выглядела нарисованной.

Галоп обрезан на 4.2 с — в оригинале в конце разворот камеры, который в цикле читается как слом.

**Порядок секций:** герой → маркеты → как работает рынок → масштаб → основания → вейтлист. Маркеты стоят сразу за героем именно потому, что они наезжают на кадр с ложей.

## Пересборка материала из исходников Higgsfield

```bash
FF=ffmpeg

# галоп: обрезать разворот камеры, ужать
$FF -i clip1.mp4 -t 4.2 -an -c:v libx264 -profile:v high -crf 24 -preset slow \
    -pix_fmt yuv420p -vf "scale=1600:-2" -movflags +faststart gallop.mp4

# ложа: в покадровый WebP (важно -c:v libwebp, иначе соберётся анимированный)
$FF -i clip2.mp4 -vf "fps=9,scale=1600:900:force_original_aspect_ratio=increase,crop=1600:900" \
    -c:v libwebp -quality 74 -compression_level 6 -start_number 1 crowd-d/%03d.webp
```

При смене числа кадров поправить `REELS.desktop.frames` / `REELS.mobile.frames` в `main.js`.
